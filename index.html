What is WebGL?

WebGL is a JavaScript API that draws graphics inside a canvas element. It talks directly to the graphics card (GPU), so it can render fast 2D and 3D scenes without plugins.

This whole page uses it: the background above and the cube below are drawn with pure WebGL, with no libraries.

How does it work?

1

Data

JavaScript sends points (vertices) to the GPU.

2

Vertex shader

A small program places every point on the screen.

3

Rasterization

The GPU turns triangles into pixels.

4

Fragment shader

Another program chooses the color of each pixel.

Minimal code

The core of a "hello triangle":

const gl = canvas.getContext("webgl");

// Link the shaders into a program
const program = gl.createProgram();
gl.attachShader(program, vertexShader);
gl.attachShader(program, fragmentShader);
gl.linkProgram(program);
gl.useProgram(program);

// Send 3 points to the GPU and draw
const points = new Float32Array([0, 0.8, -0.8, -0.8, 0.8, -0.8]);
gl.bindBuffer(gl.ARRAY_BUFFER, gl.createBuffer());
gl.bufferData(gl.ARRAY_BUFFER, points, gl.STATIC_DRAW);
gl.drawArrays(gl.TRIANGLES, 0, 3);

Uses and sources

WebGL powers browser games, online maps, data visualizations and product viewers.

Other APIs used here: Intersection Observer (scroll animations), Pointer Events (dragging the cube) and Page Visibility (pauses drawing in hidden tabs).
